# Chestnut Studio

一个简洁的视频笔记工具——边看视频边添加带时间戳的笔记。

## 截图

```
┌──────────────────────────────────────────────┐
│ Chestnut Studio — example.mp4                │
├──────────────────────┬───────────────────────┤
│                      │  笔记                  │
│  视频播放器           │  ─── 轨道1 ──        │
│                      │  [00:12] 你好         │
│                      │  [01:23] 再见         │
│                      │  ─── 轨道2 ──        │
│  ◀◀ ▶ ▶▶ ████●████  │  [00:05] 设置按钮     │
│  🔊 ─── 1.0x 01:23   │                       │
├──────────────────────┴───────────────────────┤
│ [轨道1] 输入翻译或笔记...          [发送 01:23]│
└──────────────────────────────────────────────┘
```

## 功能

- **🎬 视频播放** — 常见格式支持（mp4/avi/mkv/mov/flv），播放/暂停、倍速、音量
- **📝 时间戳笔记** — 在视频任意时刻输入笔记，自动记录时间
- **🎯 10 条轨道** — 轨道1~9,0，用颜色区分，Ctrl+1~4 快速切换
- **📋 笔记列表** — 按类型分组，点击跳转到对应视频位置
- **💾 导入导出** — JSON 格式保存/分享笔记
- **🎯 拖放打开** — 直接拖入视频文件

## 快速开始

```bash
# 安装依赖
uv sync

# 运行
uv run python main.py

# 或安装后执行
uv run chestnut
```

## 快捷键

| 按键 | 功能 |
|------|------|
| `F1` | 播放/暂停 |
| `F2` / `←` | 后退 5 秒 |
| `F3` / `→` | 前进 5 秒 |
| `Ctrl+0`~`9` | 切换轨道 |
| `Ctrl+O` | 打开视频 |
| `Ctrl+E` | 导出笔记 |
| `Ctrl+I` | 导入笔记 |
| `Enter` (输入框) | 发送笔记 |
| `Delete` (笔记列表) | 删除选中笔记 |

## 项目结构

```
chestnut_studio/
├── core/              # 核心逻辑（无 UI 依赖）
│   ├── ffmpeg.py      # FFmpeg 封装：视频信息解析
│   ├── note_manager.py # 笔记数据模型（Note/NoteManager）
│   └── track_config.py # 颜色配置
├── ui/                # UI 组件
│   ├── main_window.py  # 主窗口
│   ├── input_bar.py    # 输入栏（类型选择 + 输入框 + 发送）
│   ├── note_panel.py   # 笔记列表
│   ├── player_controls.py # 播放控制栏
│   └── cards/
│       └── player_card.py # 视频播放器
├── resources/
│   ├── icons/          # SVG 图标（Lucide 图标库）
│   ├── icon.png        # 应用图标
│   └── style.qss       # 样式表
└── utils/
    ├── log_manager.py  # 日志系统
    ├── time_utils.py   # 时间格式化工具
    └── version.py      # 版本号
```

## 技术栈

- **Python 3.12+**
- **PySide6** — Qt6 绑定
- **FFmpeg** （可选）— 视频信息解析
