# Chestnut Studio

一个简洁的视频笔记工具——边看视频边添加带时间戳的笔记。

## 功能

- **🎬 视频播放** — 常见格式（mp4/avi/mkv/mov/flv），播放/暂停、倍速、音量
- **📝 时间戳笔记** — 输入时自动记录视频位置，支持 10 条彩色轨道
- **🎯 10 条轨道** — Ctrl+1~9/0 快速切换，颜色区分
- **📋 笔记列表** — 按轨道分组，点击跳转视频位置
- **📖 术语库** — 选中笔记按 M 或右键收录术语，支持编辑/删除
- **💾 导出/导入** — TXT / JSON 格式
- **🎯 拖放打开** — 直接拖入视频文件

## 快速开始

```bash
# 安装依赖
uv sync

# 运行
uv run python main.py
```

## 快捷键

| 按键 | 功能 |
|------|------|
| `F1` | 播放/暂停 |
| `F2` / `←` | 后退 5 秒 |
| `F3` / `→` | 前进 5 秒 |
| `Ctrl+1~9` / `Ctrl+0` | 切换轨道 1~10 |
| `Ctrl+O` | 打开视频 |
| `Ctrl+E` | 导出笔记 |
| `Ctrl+I` | 导入笔记 |
| `Ctrl+Q` | 退出 |
| `Enter` (输入框) | 发送笔记 |
| `Delete` (笔记列表) | 删除选中笔记 |
| `M` (笔记列表) | 打开术语录入 |

## 项目结构

```
chestnut_studio/
├── core/               # 核心逻辑（无 UI 依赖）
│   ├── ffmpeg.py       # FFmpeg 封装：视频信息解析
│   ├── note_manager.py # 笔记 + 术语数据模型
│   └── track_config.py # 轨道数量、颜色集中配置
├── ui/                 # UI 组件
│   ├── main_window.py  # 主窗口：菜单、快捷键、拖放
│   ├── input_bar.py    # 底部输入栏
│   ├── note_panel.py   # 右侧笔记列表
│   ├── player_controls.py # 播放控制栏
│   ├── term_dialog.py  # 术语编辑/查看对话框
│   └── cards/
│       └── player_card.py # 视频播放器
├── resources/
│   ├── icons/          # SVG 图标
│   ├── icon.png        # 应用图标
│   └── style.qss       # 深色主题样式表
└── utils/
    ├── log_manager.py  # 线程安全日志系统
    ├── time_utils.py   # 时间格式转换
    └── version.py      # 版本号
```

## 构建

```bash
uv run python scripts/build_release.py
```

输出: `dist/ChestnutStudio-{version}.exe`

## 技术栈

- **Python 3.12+**
- **PySide6** — Qt6 绑定
- **FFmpeg**（可选）— 视频信息解析
